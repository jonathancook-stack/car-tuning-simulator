# 🏎️ Car Tuning Simulator

A realistic car engine swap and tuning game where you customize vehicles, install performance upgrades, and increase horsepower to dominate the streets.

## Features

### 🎮 Realistic Driving
- Smooth physics-based car handling
- Acceleration and deceleration systems
- RPM and speed management
- Realistic steering mechanics

### 🔧 Engine Swaps
- Multiple engine options from 4-cylinder to legendary V16
- Each engine comes with different base horsepower
- Progressive upgrades from budget to high-performance engines

### 🚀 Performance Upgrades
- **Turbocharger**: +50 HP ($8,000)
- **Supercharger**: +75 HP ($12,000)
- **ECU Tune**: +30 HP ($3,000)
- **Exhaust System**: +25 HP ($2,500)
- **Intake Manifold**: +20 HP ($1,800)
- **Nitrous Oxide**: +100 HP ($5,000)

### 💰 Economy System
- Start with $50,000
- Earn money by completing races and challenges
- Manage your budget for upgrades and engine swaps

### 📊 Garage System
- View detailed car statistics
- Track all installed upgrades
- Monitor current horsepower and top speed

## Controls

### Driving
- **W / Arrow Up**: Accelerate
- **S / Arrow Down**: Brake/Reverse
- **A / Arrow Left**: Turn Left
- **D / Arrow Right**: Turn Right

### Menu Navigation
- **Tune Engine**: Install performance upgrades
- **Engine Swap**: Replace your engine
- **Garage**: View car details and installed upgrades
- **Menu**: Return to main menu

## How to Play

1. **Start the Game**: Click "Start Game" from the main menu
2. **Drive Around**: Get familiar with the handling and physics
3. **Earn Money**: Complete races and challenges to earn cash
4. **Tune Your Car**: 
   - Install upgrades to boost horsepower
   - Swap engines for bigger power gains
   - Combine upgrades for maximum performance
5. **Dominate**: Use your upgraded car to win races and earn more money

## Game Progression

### Early Game
- Start with a basic 4-cylinder engine (200 HP)
- Install cheap upgrades like ECU tune and exhaust
- Complete beginner races to earn money

### Mid Game
- Upgrade to a 6-cylinder or V8 engine
- Install multiple performance upgrades
- Compete in harder races

### End Game
- Swap to a Twin-Turbo V12 or Legendary V16
- Max out all available upgrades
- Dominate the competition

## Technical Details

- **Engine**: Vanilla JavaScript with HTML5 Canvas
- **Physics**: Realistic acceleration, friction, and steering
- **Graphics**: 2D sprite-based rendering
- **Save System**: Currently in-memory (future: localStorage support)
